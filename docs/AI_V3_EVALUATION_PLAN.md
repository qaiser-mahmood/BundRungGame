# V3 evaluation gates

This plan precedes expert data collection and model fitting. It is not evidence of playing strength. See the authoritative [contract](AI_V3_PARTNERSHIP_LEARNING_SPEC.md).

1. Curate blind expert assignments with stable annotator IDs. Keep entire initial deals, near-duplicate observations and opponent policy families disjoint across training, validation and frozen holdout. Experts must not inspect future or alternate-player views of their assigned deals. Use multiple experts and report disagreement and abstentions without inventing consensus.
2. Compare regularized observable-only baselines against uniform and training-frequency priors. Report confidence-weighted Brier score, log loss, ECE, coverage and abstention for each head, with deal-level bootstrap intervals. Card comparisons must distinguish complete from partial rankings; partial rankings support only conditional comparisons. Report top-tier overlap and contradictory ranked pairs. Evaluate each expert-signal hypothesis alongside counterexamples; descriptive scenario coverage alone is not a passing result.
3. Select calibration and hyperparameters using validation only. Freeze a model/data manifest before accessing holdout. A sequence model requires adequate expert coverage and persistent baseline failure on prespecified order-sensitive cases, then a fresh comparison against the simpler model. Do not add one merely because the dataset is small.
4. Integrate only validated, calibrated models into an optional V3 policy, with observation-only inputs, uncertain/invalid/slow-model fallback and component ablations. Repeat hidden-hand/trump/metadata noninterference tests on the complete inference path. Preserve forced rules and production defaults.
5. Only then run controlled paired-partner self-play, optimizing official team outcome. Retain diverse fixed opponents and independently curated expert-play baselines, separate training/evaluation populations and a supervised reference. No reward for producing a signal or forcing reveal in isolation.
6. Freeze candidate checkpoints and run at least 1,000 fresh held-out paired initial deals against corrected-search and separately against V2. Reserve namespaces 1700000–1700999 and 1800000–1800999 only if absent from every training source. Swap team seats on equivalent deals. Report wins, signed official scores, paired 95% intervals, invalid moves, fallbacks and all ablations, including negative results. Holdout reuse after model selection requires a new holdout.
7. Measure equal completed search work separately from matched actual CPU. Equal configured wall-clock ceilings do not prove matched compute. At 8/16/32 concurrent rooms report decision and queue p50/p95/max, event-loop delay, deadline stops and fallbacks. Include extraction, model and search costs; a vectorization microbenchmark is insufficient.

No current checkpoint is cleared for these integration or promotion gates. Keep PR #4 a draft pending independent review and real supervised evidence.
